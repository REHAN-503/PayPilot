# PayPilot — PayPal Developer & Sandbox Setup Guide

This guide details the complete configuration for PayPal Sandbox, REST API Orders v2, and Webhooks integration in PayPilot.

---

## 1. Create PayPal Sandbox Accounts

1. Navigate to the **[PayPal Developer Dashboard](https://developer.paypal.com/)** and log in with your primary PayPal account.
2. In the left navigation, go to **Testing Tools** $\rightarrow$ **Sandbox Accounts**.
3. Create two accounts if not already generated by default:
   - **Business Account (Merchant)**: Represents the PayPilot merchant receiving funds.
     - Account Type: `Business (Merchant)`
     - Country: `United States (US)`
     - Note the system-generated email and password.
   - **Personal Account (Buyer)**: Used to log into the PayPal checkout modal and authorize test purchases.
     - Account Type: `Personal (Buyer)`
     - Country: `United States (US)`
     - Default balance: e.g. `$5,000.00 USD`

---

## 2. Create PayPal Developer REST App

1. Go to **Apps & Credentials** in the Developer Dashboard.
2. Ensure the toggle is set to **Sandbox**.
3. Click **Create App**:
   - **App Name**: `PayPilot AI Commerce Agent`
   - **App Type**: `Merchant`
   - **Sandbox Business Account**: Select the Business account created in Step 1.
4. Click **Create App**.
5. Copy the credentials:
   - **Client ID** $\rightarrow$ Set as `PAYPAL_CLIENT_ID` in your `.env` file.
   - **Secret** (Click "Show") $\rightarrow$ Set as `PAYPAL_CLIENT_SECRET` in your `.env` file.

---

## 3. Register Webhook Endpoint

PayPilot relies on PayPal Webhooks as the authoritative state source for payment settlement, denial, reversals, and refunds.

### Webhook URL
- **Production / Staging**: `https://<your-deployed-domain>/webhooks/paypal`
- **Local Testing**: `https://<your-tunnel-subdomain>.ngrok-free.app/webhooks/paypal` (see Step 4).

### Subscribed Event Types
In your app's dashboard under **Webhooks**, click **Add Webhook** and check the following required events:
- `CHECKOUT.ORDER.APPROVED`
- `PAYMENT.CAPTURE.PENDING`
- `PAYMENT.CAPTURE.COMPLETED`
- `PAYMENT.CAPTURE.DENIED`
- `PAYMENT.CAPTURE.DECLINED`
- `PAYMENT.CAPTURE.REVERSED`
- `PAYMENT.CAPTURE.REFUNDED`

Save the webhook and copy the generated **Webhook ID**:
- Set as `PAYPAL_WEBHOOK_ID` in your `.env` file.

## 4. Local Testing with Tunneling (ngrok or Cloudflare Tunnel)

To test real PayPal sandbox webhooks locally on `http://localhost:4000`:

### Option A: ngrok
```bash
# Start an HTTP tunnel to your local NestJS backend port
ngrok http 4000
```
Copy the generated forwarding URL (e.g., `https://a1b2-c3d4.ngrok-free.app`) and configure:
`https://a1b2-c3d4.ngrok-free.app/webhooks/paypal` as your Sandbox Webhook URL in the PayPal dashboard.

### Option B: Cloudflare Tunnel (cloudflared)
```bash
cloudflared tunnel --url http://localhost:4000
```
Use the output `trycloudflare.com` URL as your webhook endpoint.

---

## 5. Local Sandbox Simulator (No Tunnel Required)

For offline demonstrations and automated integration tests, PayPilot provides an internal Dev Webhook Simulator:
- **Endpoint**: `POST /dev/webhooks/simulate` (Active when `NODE_ENV != 'production'` and `DEMO_MODE=true`).
- **Simulated Scenarios**:
  - `PAYMENT.CAPTURE.COMPLETED` $\rightarrow$ Settles payment to `CAPTURED`, records immutable ledger entry, stamps `webhookConfirmedAt`.
  - `PAYMENT.CAPTURE.DENIED` $\rightarrow$ Transitions payment to `FAILED`, marks plan `FAILED`.
  - `PAYMENT.CAPTURE.REVERSED` $\rightarrow$ Transitions payment to `REVERSED`, appends `REVERSAL` ledger row.
  - `duplicate` $\rightarrow$ Replays an event with the same `eventId`, verifying idempotent deduplication.

---

## 6. Environment Variables Reference

Ensure your `.env` file in root or `apps/api/.env` contains:

```env
# PayPal Sandbox Configuration
PAYPAL_API_BASE_URL="https://api-m.sandbox.paypal.com"
PAYPAL_CLIENT_ID="<your_sandbox_client_id>"
PAYPAL_CLIENT_SECRET="<your_sandbox_client_secret>"
PAYPAL_WEBHOOK_ID="<your_sandbox_webhook_id>"

# Demo Mode toggle (true runs offline simulation fallback if credentials dummy)
DEMO_MODE="true"
```
